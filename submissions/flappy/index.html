Neural Flappy Trainer

ESP32 trains a population of neural-network birds directly on the OLED Flappy simulation. FPGA still streams difficulty from SW[3:0] over UART.

Training Model

  • Population: 30 birds simulated in parallel
  • Network per bird: 4 inputs -> 4 hidden neurons -> 1 output
  • Inputs: bird height, bird velocity, next obstacle distance, gap-center distance
  • Output: flap decision threshold

Evolution

  • All birds fly the same deterministic obstacle course within each generation
  • Fitness favors survival time and pipe score
  • Top birds are kept, children copy selected parents, and mutations add exploration

OLED Display

  • Generation number
  • Alive count
  • Best generation score and all-time best score
  • Compact live playfield with population dots

UART Protocol

  • DIFF:n\n: periodic difficulty stream, n from 0 to F
  • FLAP\n: optional manual generation advance/restart

Controls

  • SW[3:0]: difficulty (0 easy, F hard)
  • KEY[0]: force next generation

Build

  • FPGA: quartus_sh.exe --flow compile flappy_controller in submissions/flappy/fpga
  • ESP32: pio run -t upload in submissions/flappy/esp32
