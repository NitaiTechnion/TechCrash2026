Embedded Flappy Bird

ESP32 renders gameplay on OLED. FPGA reads KEY[0] and SW[3:0], then streams flap + difficulty over UART.

UART Protocol

  • FLAP\n: sent on each valid KEY[0] press
  • DIFF:n\n: periodic difficulty stream, n from 0 to 15

Controls

  • KEY[0]: flap while playing, restart when game over
  • SW[3:0]: difficulty (0 easy, 15 hard)

Build

  • FPGA: quartus_sh.exe --flow compile flappy_controller in submissions/flappy/fpga
  • ESP32: pio run -t upload in submissions/flappy/esp32
