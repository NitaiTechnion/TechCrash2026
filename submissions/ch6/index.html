Challenge 6: Frequency Detector

Measure an input signal frequency on the FPGA and communicate results to the ESP32 via UART.

What It Does

A frequency measurement system that:

  • FPGA: Detects rising edges on an input signal, counts edges over a measurement window, and calculates frequency.
  • Display: Shows measured frequency on HEX0–HEX5 7-segment displays.
  • Communication: Transmits frequency data to ESP32 over UART for logging or further processing.
  • Control: ESP32 sends commands to configure measurement window and trigger measurements.

Key Specifications

  • Frequency input via Arduino header pin (to be assigned)
  • Measurement window: configurable (e.g., 1 second, 10 seconds)
  • Output range: 0 Hz to 999,999 Hz (6 digits on HEX displays)
  • UART communication: 9600 baud, 8N1
  • Clock source: 50 MHz MAX10 internal clock

Development Notes

  • Start with a 1-second measurement window for simplicity.
  • Use a counter that counts on every rising edge of the input signal.
  • Trigger readout on the falling edge of a strobe signal (or use a timer).
  • Consider range: if input is < 1 MHz, display in Hz; if ≥ 1 MHz, display in MHz.
  • Ensure UART communication is robust (checksums, handshake, etc.).

Build & Run

FPGA (Quartus):

quartus_sh.exe --flow compile ch6_frequency_detector quartus_pgm.exe -c "USB-Blaster [USB-0]" -m JTAG -o "P;output_files/ch6_frequency_detector.sof"

ESP32 (PlatformIO):

cd esp32 pio run -t upload pio device monitor
