Bad Apple OLED

ESP32 drives the kit SSD1306 OLED with a high-contrast 128x64 procedural monochrome animation inspired by the classic Bad Apple style.

Wiring

OLED PinESP32 Pin
VCC3.3V
GNDGND
SDAGPIO 21
SCLGPIO 22

Build and Upload

cd demos/bad_apple_oled/esp32
$env:USERPROFILE\.platformio\penv\Scripts\pio.exe run -t upload

Files

  • esp32/platformio.ini — ESP32 PlatformIO project config
  • esp32/src/main.cpp — SSD1306 animation sketch
